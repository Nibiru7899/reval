# 2026-10-28 — LPTN identification result (P1-08)

The design-time 4-node LPTN was identified on 30 train profiles (10 s block means, `scipy.optimize.least_squares`, 33 function evaluations,
about 45 s). The fit is stable, so the 2-node fallback isn't needed.

| Test MSE (K²) | pm | stator_yoke | stator_tooth | stator_winding | mean |
|---|---|---|---|---|---|
| 4-node LPTN | 48.3 | 8.6 | 10.0 | 27.9 | 23.7 |
| For context: expert LPTN (Kirchgässner et al., 34 parameters) | | | | | 3.64 |

Model-form bands δ (95th percentile of |peak error|, test, K): pm 10–12.5, stator_winding 12.6–13.6.

Decisions:
- **Magnet loss form changed to `k_pm·ω²·i_s²`** (it was `k_pm·ω²`). Test MSE for pm dropped from 81 to 48 K². Documented in docs/05 §4 and P1-07.
- **The model is kept coarse on purpose.** The physics producer is an *independent* evidence source with an honest, wide band. A wide δ means
  physics evidence alone is often INCONCLUSIVE near the limit, and ReVal is meant to surface exactly that. Improving the LPTN, for example
  with more nodes or temperature-dependent conductances, is a possible later refinement and isn't needed for the research question.
- **Three parameters ended at their bounds** (`/C/st`, `/R/st_sy`, `/loss/k_fe2`). Revisit the bounds if the model gets refined.

The full numbers are in `examples/motor_thermal/models/lptn_report.json`, regenerated by `scripts/calibrate_lptn.py`. That file is git-ignored.
